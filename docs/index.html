How the Engine Works

Difficulty is determined strictly by the highest tier of logical technique required to solve — never by clue count. The engine uses bitwise candidates (9-bit masks, O(1) eliminate/union/intersection) for maximum performance. Each solver pass shuffles techniques within the current tier, producing a non-linear solving path that avoids biasing generation. A separate backtracking uniqueness validator runs after every clue removal, guaranteeing exactly one solution.

Tier 1 — Easy

Direct placements — no candidate elimination needed.

Tier 1Naked Singles

A cell with exactly one remaining candidate must hold that digit. When all other digits have been eliminated by peers, the last standing digit is placed.

Tier 1Hidden Singles

A digit that can only go in one cell of a row, column, or box must go there — even if that cell has other candidates.

Tier 2 — Medium

Candidate elimination across two houses, plus subset patterns within a single house.

Tier 2Pointing Pairs / Triples

When a digit's candidates within a box lie in a single row or column, eliminate it from the rest of that line outside the box.

Tier 2Claiming Pairs / Triples

Mirror of Pointing Pairs: a digit's candidates within a line lie in one box — eliminate from the rest of that box.

Tier 2Naked Pairs / Triples / Quads

N cells with N total candidates form a locked set — those digits can be eliminated from every other cell in the house.

Tier 2Hidden Pairs / Triples / Quads

N digits that only appear in N cells of a house lock those cells — every other candidate can be stripped.

Tier 3 — Hard

Multi-house patterns: fish, wings, single-digit chains, and uniqueness.

Tier 3X-Wing

A digit confined to the same two columns across two rows (or vice versa) — a size-2 fish. Eliminate it from those columns in every other row.

Tier 3Swordfish

A size-3 fish: a digit confined to exactly three columns across three rows. The 3×3 generalization of X-Wing.

Tier 3Y-Wing (XY-Wing)

A bivalue pivot {a,b} plus two bivalue pincers {a,c} and {b,c} that both see the pivot. Any cell seeing both pincers cannot be c.

Tier 3XYZ-Wing

A trivalue pivot {a,b,c} with two bivalue pincers sharing two digits with the pivot. Eliminate c from cells seeing all three.

Tier 3Simple Coloring

Conjugate-pair chains for one digit colored with two alternating colors. Two same-colored cells in a house = contradiction (false). Any cell seeing both colors eliminates the digit.

Tier 3Unique Rectangle Type 1

Four cells across two boxes. Three corners share the same pair {a,b}, the fourth has extras — eliminate {a,b} from the fourth to avoid a second solution.

Tier 4 — Impossible

Branch-and-intersect chaining, Almost Locked Sets, and exotic patterns. Computationally heavy but fully sound.

Tier 4Dynamic Cell Forcing Chains

For a cell with 2+ candidates, branch on every digit, propagate singles-only in each branch, then intersect. A placement or elimination true in EVERY branch must be true. Self-contradicting branches eliminate that digit.

Tier 4Dynamic Region Forcing Chains

Same idea as Cell Forcing Chains, but branches come from every possible placement of a digit within a single house (row/column/box).

Tier 4ALS-XZ (Almost Locked Sets)

An ALS is N cells in one house with N+1 candidates. Two non-overlapping ALSs sharing a restricted common digit X allow a shared digit Z to be eliminated from cells seeing every Z in both.

Tier 4Sue de Coq

At a box/line intersection of 2–3 cells, the candidates can be partitioned between an ALS in the rest of the line and another ALS in the rest of the box. Each ALS's digits are eliminated from its respective house.

Tier 4Exocet Pattern

A base pair on a line sharing a box (2–3 combined candidates) plus two target cells whose candidates are a subset of the base digits. Base digits are eliminated from the rest of both target boxes.
